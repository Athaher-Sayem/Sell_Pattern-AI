How it works

Raw records.
Meaningful connections.

A transparent, notebook-based workflow. Clean the data, build useful features, and let similarities reveal the customer groups.

Follow along in the notebook
The pipeline at a glanceCustomer data → Feature engineering
→ Standard scaling → PCA → Clustering
01Start with a cleaner dataset+
Load the CSV with Pandas. Fill missing income values with the median, simplify education and household categories, and prepare the data for analysis.
02Build a behavioral fingerprint+
Derive Total_Spending from six product categories, plus age, customer tenure, and total children. Encode categorical values and remove redundant source columns.
03Bring the signals into focus+
StandardScaler puts features on a comparable scale. Principal component analysis (PCA) then compresses the data into three components for clustering and visualization.
04Discover the customer groups+
Explore cluster counts using the elbow method and silhouette scores. Compare K-Means with Ward-linkage agglomerative clustering, both configured with four clusters in the notebook.
05Look beyond the cluster label+
Use the agglomerative labels for the final summaries. Compare cluster counts and average features, then inspect income versus total spending to interpret the differences.

Run it yourself
Local setup / Python environment
# Get the project
git clone https://github.com/Athaher-Sayem/Sell_Pattern-AI.git
cd Sell_Pattern-AI

# Install the notebook dependencies
python -m pip install pandas numpy scikit-learn matplotlib seaborn kneed notebook

# Open the main analysis
python -m notebook BuyPattern_AI.ipynb

Use a dedicated Python environment. Run the notebook cells in order, with the dataset in the same directory. This homepage explains the project; it does not run Python in your browser.
