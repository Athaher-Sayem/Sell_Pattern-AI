## 📌 Overview  
SmartCart Buy Pattern AI is a machine learning project that analyzes customer purchase behavior and predicts buying patterns.  

It helps to understand:
- 🛍️ What customers buy  
- ⏰ When they buy  
- 🔁 How often they buy  

This can improve:
- 🎯 Product recommendations  
- 📈 Sales strategies  
- 💡 Customer experience
